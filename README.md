# 🌟 Vegas Digital Menu 🌟

Sistema completo de cardápio digital para o Vegas Motel, desenvolvido em PHP puro e MySQL.

## ✨ Características

- 🎨 Design temático (preto, vinho, roxo com elementos neon)
- 📱 Totalmente responsivo
- 🔐 Painel administrativo com autenticação
- 🛡️ Proteção contra SQL Injection
- ✏️ CRUD completo de produtos
- 📋 100+ produtos pré-cadastrados
- 🌐 URLs amigáveis

## 🚀 Acesso Rápido

- **Cardápio Público:** `/` ou `/cardapio`
- **Painel Admin:** `/painel/login.php`
- **Credenciais:** `admin` / `admin`
